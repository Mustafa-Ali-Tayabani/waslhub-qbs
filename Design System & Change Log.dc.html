Status tags

One component, 22 variants. Colours are fixed semantic tokens, independent of the tenant brand, so a tenant colour can never collide with a status. Every tag has an icon, so colour is never the only signal. Hover any tag for its tooltip.

Theme tokens

Tenants set one value — brand. The rest are derived: on-brand text flips to dark when white fails 4.5:1, and brand-text is darkened until it passes 4.5:1 on white. Swapping a theme is a token swap.
